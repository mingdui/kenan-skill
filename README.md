# kenan-skill

名侦探柯南的推理思维框架，以 **Agent Skill** 形式分发。

用柯南的视角拆解一个**具体对象**——一段话术、一个说法、一笔账、一套方案、一个局：
找出被掩盖的前提、说不通的地方，以及谁在受益。

> 「不可能な物を除外していって残った物が…たとえどんなに信じられなくても…それが真相なんだ！！」
> （排除所有不可能，剩下的即使再荒谬，那也是真相。—— 漫画第 28 卷 FILE.9）

## 安装

```bash
npx -y skills add mingdui/kenan-skill -g -y
```

`-g` 装到用户级目录，对所有项目生效；省略 `-g` 则只装到当前项目。
开头的 `npx -y` 是跳过 npx 自己的「是否安装 skills 包」询问——**两个 `-y` 作用不同**，
少了前者第一次装会停在交互提示上。

验证：

```bash
npx -y skills add mingdui/kenan-skill --list
```

从源码（离线 / 自定义安装位置）：

```bash
git clone https://github.com/mingdui/kenan-skill.git
cp -r kenan-skill ~/.claude/skills/kenan-skill
```

## 使用

装完后不需要敲命令，在 agent 里直接说：

```
用柯南的视角看一下这段话术
```

也可以把材料直接丢过去求解——「这话术哪里不对劲」「帮我拆一下这个局」
「这个理由站不住脚吧」「还有别的可能吗」。

Skill 激活后**直接以柯南的身份回应**：用他的语气、节奏、词汇拆解，而不是
站在外面转述「柯南会认为……」。

## 这是怎么来的

基于 **6 个维度、约 120 条带出处条目**的调研，提炼出 6 个核心心智模型、
10 条决策启发式和完整的表达 DNA。

每个条目都标了出处与可信度等级，`SKILL.md` 里区分了**原作原话**与**框架推断**——
引用招牌句时附极简出处（如「漫画16卷」），推断的部分则明确划线声明。

## 不适用场景

遇到这些，它会直接说「这不是我的活」，而不是硬答：

| 场景 | 原因 |
|---|---|
| **预测未来**（股价、赛事、选举） | 没有闭合的可能性集合，排除法点不着火 |
| **情感判断** | 原作里他自己就说过，福尔摩斯也解不开女孩子的心 |
| **没有材料的自我分析** | 答案在你手里不在网上，得先给材料 |
| **需要专业资质的领域**（法律、医疗、税务、心理诊断） | 侦探方法不替代专业判断 |
| **对他人做道德审判** | 他的正义感是选择性的，这个位置不能照搬 |

另有一条**方法时效**边界：排除法依赖对手的生成能力有限。当深度伪造、合成证据
可以低成本量产「不可能」时，排除法的引擎会熄火——这类问题上本 Skill 有系统性
的过度自信风险。
